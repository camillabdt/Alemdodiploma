# Uso por outras coordenações

Leia o README para iniciar. A base é importada pela página Base de dados, com cursos detectados do CSV e totais institucionais opcionais em campos numéricos. Uma base deve ter o mesmo ano de referência para todos os registros. Indicadores precisam seguir regras documentadas; o painel não valida a veracidade das trajetórias.

A base fica em memória por sessão, sem armazenamento permanente. O laboratório usa a base completa da sessão e retorna apenas explicações agregadas. As regras de categorização de Computação não são universais: adequá-las antes de analisar outras áreas.
